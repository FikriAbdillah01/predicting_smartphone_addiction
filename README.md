# Smartphone Addiction Prediction

Repository ini digunakan untuk mencatat apa saja yang ditemukan saat kompetisi kaggle, predicting smartphone addiction, berlangsung. Kompetisi ini dimulai tanggal 1 agustus 2026 di Kaggle competition. Tujuan dari kompetisi ini adalah melatih kemampuan machine learning seorang peserta. The submissions are evaluated on area under the ROC curve.
